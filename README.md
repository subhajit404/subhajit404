## About this logo

This animated recreation preserves the original mark's structure: a coiled serpent built from alternating **green scaled bands** and **white striped segments**, three **red-ringed gear cogs** woven between the coils, a **checkered viper head** with a flicking tongue, and a **red rattle tail**.

### Animations included

| Element | Effect | Timing |
|---|---|---|
| Whole body | Gentle sway (like a snake shifting weight) | 4.5s loop |
| Head | Subtle nod following the body sway | 4.5s loop |
| Tongue | Quick flick/dart | every ~2.4s |
| Eye | Soft blink | every ~3.6s |
| 3 gears | Continuous rotation (alternating directions, mimicking meshed gears) | 8–9s loop |
| Rattle tip | Shake/rattle wiggle | 0.7s loop |
| Stripe segments | Faint opacity pulse for a "living pattern" feel | 3s loop |

### Usage notes

- This is a **self-contained SVG with embedded CSS animation** — it will animate in any Markdown renderer that supports raw HTML/SVG (GitHub renders the static frame only, but it displays and animates correctly in browsers, VS Code preview, Obsidian, and most static-site generators).
- To use it as a favicon/loading spinner, extract the `<svg>...</svg>` block into its own `.svg` file — the `<style>` block travels with it.
- Colors are defined as CSS variables (`--ink`, `--green`, `--red`, `--white`) at the top of the `<style>` block for easy re-theming.
- All motion is subtle and loops seamlessly with no abrupt resets, so it can run indefinitely as a hero/brand mark.
